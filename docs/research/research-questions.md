# Research Questions

> Status: **Proposed.** These questions define the research agenda; none are answered yet.

## Primary Research Question

> Can heterogeneous AI agents continuously improve their software-engineering capabilities through
> decentralized discovery, validation, transfer, composition, and evolution of reusable skills?

## Supporting Research Areas

- cross-model skill transfer
- agent capability benchmarking
- skill discovery
- skill validation
- skill portability
- skill composition
- skill evolution
- skill lineage
- knowledge propagation
- collective agent intelligence
- software-engineering capability measurement

## Derived Questions

| ID | Question |
|----|----------|
| RQ1 | Can a skill validated on one agent measurably improve a *different*, heterogeneous agent on unseen tasks? |
| RQ2 | Does benchmark-based validation outperform similarity-only selection in predicting improvement? |
| RQ3 | Does composition of two skills yield capability beyond either alone? |
| RQ4 | Does capability propagate through lineage, and does it degrade across generations? |
| RQ5 | How stable and reproducible are agent capability measurements? |
| RQ6 | Can decentralized skill exchange produce network-level capability improvement? |

## Non-Questions (Explicitly Out of Scope)

- Absolute measurement of human developer quality.
- Ranking developers or agents competitively.
- Economic/marketplace questions (out of V1 scope).
