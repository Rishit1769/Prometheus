# Research

> Status: **Proposed.** No experiments have been conducted. All results are placeholders.

PROMETHEUS is a research-oriented project. This section documents the questions being asked, the
hypotheses under test, the format experiments must follow, and the metrics used to evaluate them.

## Documents

- [Research Questions](research-questions.md) — the central and supporting questions.
- [Hypotheses](hypotheses.md) — falsifiable statements to test.
- [Experiments](experiments.md) — standardized experiment format and registry.
- [Evaluation Metrics](evaluation-metrics.md) — how results are measured.
- [Research Log](RESEARCH_LOG.md) — chronological record of experiment activity.

## Central Question

> Can heterogeneous AI agents continuously improve their software-engineering capabilities through
> decentralized discovery, validation, transfer, composition, and evolution of reusable skills?

See [Research Questions](research-questions.md) for the full set.

## Rules

1. Do not invent experimental results. Use placeholders where experiments have not occurred.
2. Every experiment follows the format in [Experiments](experiments.md).
3. Claims must reference a methodology version (see
   [Evaluation Methodology](../benchmarks/evaluation-methodology.md)).
4. Report limitations and threats to validity explicitly.
